# 制作課題

- 　以前の課題で作成したテキストRPG風・冒険コマンドゲームに画面をつけて操作できるようにしようとしました

- ゲームの機能自体を実装させるのは難しく、やり方も現状では理解が難しそうだったので名前入力画面やセーブ、ロード機能のあるゲーム機能の土台に出来そうなページを作成しました
### 実装できた機能
- 名前を入力しゲームメニュー画面への移動

- 終了ボタンで名前入力画面への移動

- jsonに保存されたプレイヤーのステータスをゲームメニュー画面に表示する

- 入力した名前をステータスとして表示する

- セーブボタンでセーブメニューへ移動、戻るボタンでメニュー画面に移動

- セーブするファイルの選択

- 空のデータには空きデータ、セーブ済みのデータはステータスの表示する

- ロードボタンでデータ選択画面に移動、戻るボタンで開始画面に移動

- セーブしたデータを再開する

### 実装したかったけど出来なかった機能
- 戦闘や移動などゲーム自体の処理
